# 言外之意 · Between the Lines

[English](README.md) | 简体中文

**有些话没有说出口，却悄悄改变了你的位置。**

《言外之意》是一部关于关系、沟通与个人边界的互动职场小说。你将成为一名研发专员，经历一场缺席的欢送会、一张被卡住的采购单，以及办公室里逐渐传开的流言。听懂对方的话，决定自己的回应，找到属于你的相处方式。

**[在浏览器中开始体验](https://www.openwook.cloud)** · 无需安装 · 中文剧情与界面

## 走进故事，做出回应

三个幕次，将日常职场片段变成关于信任、责任与个人付出的选择：

- **一场没有通知你的欢送会。** 询问发生了什么，表达自己的感受，重新考虑你对这段友谊的期待。
- **一张迟迟无法推进的采购单。** 确认要求、准备材料、寻求支持，让项目继续前进。
- **跟着你走进办公室的流言。** 核对事实，选择回应方式，确定工作与私人关系之间的边界。

你可以用自己的话与同事交谈，也可以选择剧情提供的行动。AI 对话让角色回应你的表达，重大选择会在执行前请你确认。你的行动将影响故事的走向，以及最后留下的关系。

## 开始体验

1. 在电脑或手机上打开[游戏](https://www.openwook.cloud)。
2. 点击 **“知乎授权登录”**，完成授权后开始新故事。线上游戏仅支持知乎登录。
3. 阅读场景，选择行动，或向当前角色输入想说的话。通过手机和剧情面板，回看对话、材料与当前进展。
4. 再次进入时，点击 **“继续上次的故事”**，或在 **“查看全部存档”** 中选择另一段经历。

已有试玩玩家需要先登录知乎才能继续。在原七天试玩有效期内，使用原浏览器授权可继承已保存进度；访客会话过期或丢失后无法自动找回。如果绑定时还有回合正在进行，进度会在该回合结束后转移。换一台设备时，使用同一个知乎账号即可继续。

## 给另一种回应留些空间

每个存档都是独立的一段经历。你可以重新开始，尝试另一种应对方式；也可以回看已经结束的故事，或把暂时不想继续的存档归档。移入回收站的存档可在三十天内恢复。

故事结束后，回看发生过的事，思考自己的选择。你不必保留每一段友谊，也不必每次都作出相同的回应。

## 游玩时可以留意

- **目前提供中文剧情与界面。** 英文 README 用于介绍产品，不代表游戏已有英文模式。
- **对话与行动相互配合。** 如果一句话没有推进剧情，可以查看当前可选行动或待补材料。重要决定可能需要单独确认。
- **断线后可以回来继续。** 重新打开存档，等待当前回合恢复；如页面提示需要处理，使用对应的恢复或重试入口。
- **AI 功能有使用额度。** 对话或回顾暂不可用时，请按页面提示操作。确定性剧情行动与 AI 请求使用不同的预算。
- **故事仍在持续完善。** 实际场景和功能以当前上线版本为准；旧存档可能保留早期剧情，或仅供回看。

## 当前故事范围

本版专注三幕职场主线，以及你与同事之间的工作和私人边界。谢川伴侣线、家庭支持短场景尚未作为可玩内容提供；推进剧情不会自动替你决定分手、和好、接受建议或释然。详见[故事范围](docs/story-scope.md)。
