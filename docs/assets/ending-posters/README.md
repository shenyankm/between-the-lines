# 结局海报素材基线

来源：[飞书文档](https://ccnoz23f7y98.feishu.cn/wiki/Ka47wg91jiUW1ekAcbFc9Fuonqe)，文档 token CnsUd1pnyoO1dsxTEACcDA6SnYI，版本 1064，2026-09-14。六张原始 PNG 仅供对照；不进入产品资源引用。

按文档顺序为 E01 改写规则、E02 各自为界、E03 有限修复、E04 主动转身、E05 付出代价、E06 尚未破局。映射不改变服务端结局优先级。哈希和清理后文件路径见 provenance.json。

每张分别调用 imagegen 编辑，使用对应原图为唯一参考：去掉标题、固定正文和手写文字；保留人物、姿势、服装、场景、构图、纸张、边框、叶片与色调；清理文字区域后还原空白纸张，不加入新物体或新文字。六张结果均人工查看。生成具有局部像素变化，不是对原图的无损文字分层。

前端只引用清理后的 WebP。重建命令为 `python scripts/build-images.py`，需要 Pillow；本次使用 Codex 已捆绑的 Pillow runtime，没有创建 Python 环境。480、768、941px 不超过处理后原图宽度。

字体和排版按用户补充要求改为纵向海报：大号居中宋体、右上编号、带字距的收束状态与副标题、通栏插画、下方正文。原始位图不含可提取字体文件，使用本地托管 Noto Serif SC 近似原图字形。动态正文不会照抄原图中与本局事实冲突的固定结论。
