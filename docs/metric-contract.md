# V3 metric contract

The four values describe this playthrough. Work and relationship facts determine endings; none of these values is a substitute for evidence, approval, delivery, or a personal choice. The stage shows the four values, and committed effect receipts explain actual, clamped deltas.

| Metric     | Sources                                                                          | Observable behavior                                                                              | Does not do                                                                                       |
| ---------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| Credit     | Boundary expression, reporting, materials, delivery, project responsibility loss | Numeric receipt and ending reflection                                                            | Override evidence or financial authority; choose an ending by score                               |
| Rumination | Rumor, confrontation, temporary restraint, boundaries, contact                   | Describe the protagonist's experience in the ending                                              | Reveal private psychology to NPCs; define personality, failure, forgiveness or departure          |
| Pressure   | Procurement obstruction, rumor, delivery, support, rest                          | Describe workload and relief after the actual recorded arrangement                               | Automatically request leave or mark a support application completed                               |
| Heat       | Public confrontation, rumor, clarification, delivery                             | At 70+, an action settlement records company review once; the event receipt exposes its evidence | Decide responsibility, resolve the rumor, substitute for delivery, automatically change an ending |

Company review means checking existing work records. It does not grant an NPC access to private dialogue or mental state. The current NPC context contains selected facts, not these four numeric values. There is no numeric NPC tone, coordination-cost or approval-difficulty mechanism. Such additions require a separately tested content revision.

This contract describes the existing rules; it does not introduce a content revision or rewrite old saves. Tests compare fixed facts at low/high values, and the existing heat threshold at both sides. Real-model and target-player observations remain unperformed.
