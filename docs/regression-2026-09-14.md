# 2026-09-14 全面回归记录

基线：`3189831`，本报告及修复提交至 `codex/ai-npc-integration` 分支，不创建或合并 PR。

## 发现并修复

1. **阅读进度倒退。** 快速重复点击后，旧的 `/reading` 请求晚于后续请求返回，会把第三句退回第二句。服务端和查询缓存本来已保证进度单调递增，但组件本地状态直接覆盖。现统一使用最大位置。新增延迟响应回归测试，修复前稳定失败、修复后通过。
2. **AI 对已有材料的描述不准确。** 真实 GPT6 的一条回复仍要求“补齐报价和用途说明”，而 V3 原申请已附这些材料。新增仅适用于 V3 的事实约束，区分模板要求、已提交附件和真正缺项。修正后三次真实调用均说明原材料已提交，并建议核对退回依据；这不代表能够保证所有未来生成都正确。
3. **V3 语义评测无法运行。** 评测初始化重复执行第二幕已经记录的采购提交，随后补材料也没有提供新版要求的证据参数。按当前剧情和表单要求修正，12 个样例全部通过。
4. **GPT6 测试配置漏入工程。** `playwright.gpt6.config.ts` 未纳入 TypeScript 工程，导致完整 ESLint 检查失败。已加入配置。
5. **格式检查与生成契约冲突。** `src/testing/story.json` 由 Python 导出且受契约检查保护，Prettier 却要求改写其格式。现与生成的 API 类型一样排除格式重写，仍由契约检查校验内容。

此外，强化真实 GPT6 浏览器测试：只接受本轮新增的 NPC 回复，并检查回合完成、模型为 `gpt-6-astra`、实际调用次数和 token 用量，避免旧对白导致误报成功。

## 环境及验证边界

- Windows、Miniconda Python 3.13.15、Node 22.23.2、PostgreSQL 17.11、Playwright Chromium；桌面及手机视口均覆盖。
- 浏览器模拟测试使用独立 `btl_e2e`，后端集成和恢复演练使用 `btl_test`。真实调用使用专门测试身份/存档或内存检查点，未修改用户正在玩的存档。
- Windows 的独立进程演练使用外部适配器指定 SelectorEventLoop；直接运行默认 Uvicorn 的 ProactorEventLoop 与 psycopg 异步连接不兼容。本机启动助手已指定正确事件循环。
- **Linux 发布/部署链路未全部验证。** 本机没有 Docker；额外运行发布脚本测试时，`fcntl` 导入和 `os.pwrite` 在 Windows 不可用。未把这些失败算作通过，也未用空实现绕过验证。容器构建、Nginx 日志脱敏、生产部署/回滚仍需在 Linux CI 环境验证。
- 真实 AI 结果是有限样例抽查；语气自然度及所有自由输入的正确性无法由固定样例保证。第三方额度价格未知，不报告为免费。
