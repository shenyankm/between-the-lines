# Ending Serif

Noto Serif SC, weights 400–600, SIL Open Font License 1.1 (OFL.txt).
Official source: https://fonts.google.com/noto/specimen/Noto+Serif+SC
Retrieved 2026-09-14 from Google Fonts CSS2; original source URLs and hashes are recorded in sources.json.

101 WOFF2 subsets (6,027,992 bytes total) are self-hosted. CSS unicode-range requests only subsets needed for visible ending text. No runtime Google Fonts connection, font preload on ordinary story pages, or extra JS dependency. CSS family alias Ending Serif scopes usage to the ending poster and its canvas. Browsers without a loaded font fall back to Songti SC / SimSun / serif; PNG preparation explicitly awaits relevant glyphs and fonts.ready.
